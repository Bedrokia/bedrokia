# Bedrokia

Serveur **Minecraft: Bedrock Edition** écrit en C# / .NET 10. Bedrock 26.50 (protocole 2193), connexion NetherNet.

> ⚠️ **Projet codé avec l'IA, et un peu d'humain.** Presque tout le code a été écrit par une IA (Claude, d'Anthropic,
> via Claude Code), guidée et testée en jeu par un humain. Le but : tester ce que l'IA sait faire sur un vrai logiciel,
> et montrer qu'elle peut aussi le **maintenir**. Lire [Le projet et l'IA](ia).
